# ViralCut 1.5.13

**Локальная нарезка видео в вертикальные клипы. Всё считается на вашем
компьютере — видео никуда не отправляется.**

Главное в этом релизе: приложение больше не забирает всю машину, видеокарту
можно выбрать самому, а субтитры выходят на языке ролика. Плюс появилась
сборка для **Intel Mac**.

---

## 🎚 Процессор под контролем

В настройках два ползунка, которые решают, сколько машины отдавать обработке:

- **Мощность** — сколько клипов рендерить параллельно и сколько потоков дать
  каждому ffmpeg.
- **Не более N% процессора** (25–100) — жёсткий потолок загрузки. Раньше один
  ffmpeg с 8 потоками мог занять все ядра даже при низкой «мощности».

Как это работает на разных системах:

| Платформа | Механизм | Что это значит |
|---|---|---|
| Windows | Job Object, `CPU_RATE_CONTROL_HARD_CAP` | потолок держит планировщик Windows |
| macOS / Linux | диспетчер пауз (`SIGSTOP`/`SIGCONT`) | рендер приостанавливается, когда норма выбрана |

Замер на рендере 1080p: **пик 82% → 62%** при лимите 40%. Лимит применяется
на лету, без перезапуска.

## 🖥 Встроенная или дискретная видеокарта

На ноутбуках два адаптера, и система часто выбирает встроенный. Теперь в
настройках есть переключатель «Авто / Встроенная / Дискретная»:

- **Windows** — предпочтение записывается в систему для приложения и для
  ffmpeg (`UserGpuPreferences`), а порядок аппаратных кодировщиков меняется:
  дискретная → NVENC/AMF, встроенная → Quick Sync.
- **macOS Intel** — сборка идёт с отключённым автопереключением графики
  (`NSSupportsAutomaticGraphicsSwitching = false`), то есть считает на
  дискретной AMD, а не на встроенной Intel.
- Виджет показывает выбранную карту, вендора и пометку «дискретная», а в
  настройках видно все найденные адаптеры.

## ✍️ Субтитры на языке ролика

Русские ролики больше не получают английские субтитры:

- резервные субтитры площадки выбираются по языку, а не по алфавиту файлов
  (раньше `subs.en.vtt` подхватывался раньше `subs.ru.vtt`);
- язык определяется **до** распознавания — по двум фрагментам с речью, а не по
  первым 30 секундам, поэтому музыка и интро больше не уводят в английский;
- если текст вышел на другом алфавите, распознавание повторяется один раз;
- в лог пишется `[whisper] язык: ru (0.99)` — по нему сразу видно, что решила
  модель.

## 🧠 Меньше вылетов на длинных видео

Анализ громкости, смеха и аплодисментов держал всё аудио в памяти: часовое
видео — ~230 МБ, трёхчасовое — ~700 МБ. Теперь аудио читается блоками по
30 секунд, результат совпадает до бита, памяти нужно ~2 МБ.

## 🍎 Intel Mac

Отдельная сборка для Mac на процессорах Intel (x86_64): свой Python, свои
колёса зависимостей и x64 Node для поиска HD-версий на YouTube. Собрана и
проверена под Rosetta на Apple Silicon — полный цикл рендера проходит.

## ⚙️ Установка

**macOS.** Откройте DMG, перетащите приложение в «Программы». Первый запуск —
ПКМ по приложению → «Открыть» (подпись ad-hoc). Или в терминале:

```bash
xattr -dr com.apple.quarantine /Applications/ViralCut.app
```

**Windows.** Распакуйте архив целиком и запустите `ViralCut.exe`. SmartScreen
скажет «Неизвестный издатель» — это нормально для неподписанной сборки:
«Подробнее» → «Выполнить всё равно». Без установки — распакуйте и запустите
`ViralCut.bat`.

**Если не открылось:** Windows — `ViralCut-console.bat` покажет ошибку, лог в
`%APPDATA%\ViralCut\app.log`. macOS — `~/Library/Application Support/ViralCut/app.log`.

Полный список изменений — в [CHANGELOG.md](https://github.com/vanwild11/viralcut/blob/main/CHANGELOG.md).
