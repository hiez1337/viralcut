# ViralCut 1.4.3 (Fork Lite #2) — Windows x64 без CUDA DLL

Облегчённая портативная сборка форка [`hiez1337/viralcut`](https://github.com/hiez1337/viralcut) на базе **ViralCut 1.4.3** для Windows 10/11 (x64), не требующая установки Python.

> Полный журнал всех модификаций форка: [CUSTOM_CHANGES_ru.md](https://github.com/hiez1337/viralcut/blob/custom/CUSTOM_CHANGES_ru.md) · [CUSTOM_CHANGES.md (EN)](https://github.com/hiez1337/viralcut/blob/custom/CUSTOM_CHANGES.md)

## Что нового в `fork-v1.4.3-2`

### Исправление выбора аудиодорожек YouTube (оригинал вместо автодубляжа)
- **Умное ранжирование аудиопотоков (`custom_downloader.py`):**
  - Ранее на видео с многоязычным дубляжом YouTube (до 20+ звуковых дорожек с идентичным битрейтом 129 kbps) загрузчик выбирал первую дорожку по алфавиту языка (`140-0` арабский).
  - Теперь дорожки с `language_preference < 0` или пометкой `dubbed` пенализируются, а оригинальная дорожка (`language_preference > 0` или `original`/`default`) получает наивысший приоритет.
- **Интерактивный переключатель языка в карточке Whisper:**
  - На главном экране добавлены стильные кнопки-таблетки: **`Авто`**, **`Русский (RU)`**, **`English (EN)`** и **`Оригинал`**.
  - Выбранный язык сохраняется между перезапусками приложения (`data/whisper.json`) и автоматически передаётся в загрузчик фрагментов и модуль распознавания.
- **Повышенная надёжность Whisper на вступительных шумах и музыке (`transcribe.py`):**
  - Контекст автодетекции языка расширен с 1 до 2 сегментов (60 секунд речи вместо 30), что предотвращает ложную фиксацию чужого языка из-за вступительной музыки.
  - Добавлена защита от ложных низковероятных классификаций нелатинских языков (`ar`, `he`, `ur`, `cy`, `fa`, `hi` с уверенностью `< 0.65`).

### Автоматизация релизов
- **Сборка и публикация прямо в GitHub Actions (`custom-release.yml`):**
  - Добавлен автоматический шаг создания GitHub Release (`gh release create`) с загрузкой артефактов и автоматической генерацией контрольных сумм SHA256.

### Возможности форка (включены в эту сборку)
- **Whisper `small` по умолчанию + выбор модели в интерфейсе (`Small` / `Medium` / `Large v3`):**
  - прямо на главном экране заранее видны размер весов, требования к VRAM/RAM, скорость, точность и статус на диске (`Готова` / `↓ ~XXX МБ`);
  - кнопка **«Скачать»** позволяет загрузить модель заранее с живым прогресс-баром, скоростью (МБ/с) и ETA;
  - выбранная модель запоминается между запусками (`whisper.json`).
- **YouTube 1080p в экономном режиме** и поддержка перерендера готовых эконом-клипов.
- **Live-инспектор (`Ctrl+Shift+D`)** с телеметрией GPU/VRAM, CPU/RAM, Whisper, YouTube и дочерних процессов `ffmpeg`.
- **Карточка «Диск и очистка»** в Инспекторе (`Очистить временные` и `Удалить исходники`) без удаления готовых клипов и моделей Whisper.
- **Автопроверка обновлений отключена по умолчанию** (включается тумблером в интерфейсе).
- **Безопасный откат Whisper на CPU** при отсутствии CUDA/cuDNN DLL в системе (без краша `ctranslate2`).

## Ограничения лёгкой сборки (без CUDA DLL)

1. **Распознавание речи Whisper работает на CPU**, если в вашей системе не установлены системные библиотеки NVIDIA CUDA 12 + cuDNN 9 (для CPU комфортнее модель `Small` по умолчанию). При этом аппаратное ускорение рендера видео **`h264_nvenc`** на картах NVIDIA продолжает работать через обычный видеодрайвер.
   - Для быстрого Whisper (`Medium` / `Large v3`) на видеокарте NVIDIA скачайте [архив ветки `custom` (ZIP)](https://github.com/hiez1337/viralcut/archive/refs/heads/custom.zip) и запустите через `run_windows.bat` (он автоматически установит `nvidia-cublas-cu12` и `nvidia-cudnn-cu12`).
2. **Модели Whisper не вшиты в архив** — нужная модель скачается при первом запуске или кнопкой **«Скачать»** в интерфейсе (`Small` ~465 МБ, `Medium` ~1.46 ГБ, `Large v3` ~2.95 ГБ).
3. **Предупреждение Windows SmartScreen** — `.exe` не подписан платным сертификатом; при первом запуске нажмите *«Подробнее» → «Выполнить в любом случае»*.
4. **Нужен Microsoft Edge WebView2 Runtime** — уже встроен в Windows 11 и актуальную Windows 10.
5. **Node/PO-token провайдер не вшит** — при ограничениях YouTube включите **«Cookies из браузера»** в параметрах нарезки.

## Как запустить

1. Скачайте `ViralCut-1.4.3-fork.2-windows-x64-lite.zip` из блока **Assets** ниже.
2. Распакуйте архив в папку с латинским путём (например, `C:\ViralCut`).
3. Запустите `ViralCut\ViralCut.exe`.
