# ViralCut 1.5.18

**Локальная нарезка видео в вертикальные клипы — теперь с ИИ-агентом, который
всё делает сам. Видео никуда не отправляется, пока вы сами не подключите ИИ.**

Большое обновление: внутри приложения появился помощник и агент, ИИ-режим
нарезки, выбор моделей и жёсткие лимиты на железо.

---

## 🤖 Агент: сказал — сделал

Включите **«Агент-режим»** в настройках, и приложение перестаёт быть просто
инструментом: оно выполняет задание по шагам, пока не доведёт до результата.

- «нарежь 5 клипов с ИИ-режимом, сделай субтитры крупными и жёлтыми, вырежи паузы» —
  агент сам поставит настройки и запустит нарезку;
- «поставь лимит 40% процессора» — применит сразу;
- «выбери дискретную видеокарту» — переключит предпочтение GPU;
- «пересобери второй клип в 1:1 с розовым акцентом» — пересоберёт.

Агент работает до 6 шагов, видит результат каждого действия и сам исправляется,
если что-то не получилось. В чате видно каждый шаг.

## 💬 Помощник, который объясняет всё с первого запуска

При первом открытии сама появляется панель «Помощник»: приветствие с учётом
состояния и готовые вопросы. Он знает про приложение всё — 15 разделов: как
нарезать, ИИ-режим, ключи, субтитры, лимиты, видеокарта, **плагины и YouTube**,
требования Windows, паузы, дорожки звука, эфиры, где лежат файлы.

Отвечает двумя способами: с ключом ИИ — моделью (видит состояние приложения),
без ключа — по встроенной инструкции. Так подсказки есть у всех, даже офлайн.

## 🎬 ИИ-режим нарезки

Галочка «ИИ-режим» и задание словами: «нарежь самые вирусные моменты, без
вступлений». Модель получает расшифровку с таймкодами и сама выбирает границы
клипов, придумывает хуки и подписи. Клипы собираются сразу, без лишних кликов.

## 🔑 Любая модель: облако или свой компьютер

| Провайдер | Что это |
|---|---|
| **DeepSeek** (основной) | свой ключ, тарификация напрямую |
| **Polza.ai** | агрегатор: один ключ на сотни моделей (OpenAI, Claude, Qwen, DeepSeek…) |
| **OpenAI** | GPT-4o mini / 4o |
| **Локальная модель** | Ollama или LM Studio — данные не покидают компьютер, ключ не нужен |
| **Свой сервер** | любой OpenAI-совместимый API |

Ключ хранится локально (права 0600), в интерфейс и логи не попадает. Модель
выбирается из каталога провайдера, у Polza.ai это 282 текстовые модели.

## 🎚 Нагрузка под контролем

- **Ползунок мощности** — сколько рендеров параллельно.
- **«Не более N% процессора»** — жёсткий потолок: на Windows его держит система,
  на macOS — диспетчер пауз. Замер: пик 82% → 62% при лимите 40%.
- **Выбор видеокарты** — встроенная или дискретная; на Windows предпочтение
  пишется в систему, на Intel Mac сборка считает на дискретной AMD.

## ✍️ Субтитры на языке ролика

Резервные субтитры площадки выбираются по языку, а не по алфавиту файлов, язык
определяется по фрагментам с речью (а не по первым 30 секундам), текст
проверяется по алфавиту, строки не выходят за кадр.

## 🍎 Intel Mac

Отдельная сборка для Mac на Intel (x86_64), собрана и проверена под Rosetta.

## ⚙️ Установка

**macOS.** DMG → перетащить в «Программы». Первый запуск — ПКМ → «Открыть»
(подпись ad-hoc). Или: `xattr -dr com.apple.quarantine /Applications/ViralCut.app`.

**Windows.** Распакуйте архив целиком и запустите `ViralCut.exe`. SmartScreen:
«Подробнее» → «Выполнить всё равно». Без установки — `ViralCut.bat`.

**Если не открылось:** Windows — `ViralCut-console.bat` покажет ошибку; лог в
`%APPDATA%\ViralCut\app.log`. macOS — `~/Library/Application Support/ViralCut/app.log`.

**Первый запуск ИИ:** настройки → «ИИ-помощник» → вставьте ключ DeepSeek
([получить](https://platform.deepseek.com/api_keys)) или выберите Polza.ai /
локальную модель.

Полный список изменений — в [CHANGELOG.md](https://github.com/vanwild11/viralcut/blob/main/CHANGELOG.md).
