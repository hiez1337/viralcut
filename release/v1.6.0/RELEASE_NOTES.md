# ViralCut 1.6

ViralCut нарезает длинные видео в вертикальные клипы для Shorts, Reels и TikTok. В этом выпуске помощник умеет работать с конкретными клипами, а загрузка с YouTube даёт явный выбор качества.

## Что нового

- **Помощник видит клипы проекта.** Номера и таймкоды помогают выполнить команду «Сделай субтитры в первом клипе жёлтыми». Команда «Отмени последнюю правку» возвращает предыдущую версию клипа. История отмены доступна до перезапуска.
- **Локальный и подключённый режимы.** Базовые команды доступны без ключа. Для работы с выбранной моделью сохраните один ключ в настройках ИИ. Ключ привязан к провайдеру и адресу API.
- **YouTube.** Доступны Full HD 1080p, 720p и 480p. При HTTP 503 приложение повторяет попытку в выбранном качестве. Перед нарезкой оно проверяет разрешение и наличие звука.
- **Субтитры на языке речи.** Распознавание сохраняет русский или английский. Резервные субтитры площадки используются только при совпадении языка.
- **Три новых шрифта с кириллицей.** Geologica Bold для основных субтитров, IBM Plex Sans Condensed SemiBold для длинных реплик и Rubik Mono One для коротких заголовков.

## Установка

| Платформа | Архив | Запуск |
|---|---|---|
| macOS · Apple Silicon | `ViralCut-1.6.0-macOS-arm64.zip` | Распакуйте и откройте `ViralCut.app` |
| macOS · Intel | `ViralCut-1.6.0-macOS-x86_64.zip` | Распакуйте и откройте `ViralCut.app` |
| Windows 10/11 x64 | `ViralCut-1.6.0-windows-x64-portable.zip` | Распакуйте всю папку и запустите `ViralCut.exe` |

Архивы включают зависимости и модель Whisper. Исходники доступны по тегу `v1.6.0`. Контрольные суммы SHA‑256 лежат рядом с файлами релиза.
