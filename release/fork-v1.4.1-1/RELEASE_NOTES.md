# ViralCut 1.4.1 (Fork Lite #1) — Windows x64 без CUDA DLL

Облегчённая портативная сборка форка [`hiez1337/viralcut`](https://github.com/hiez1337/viralcut) для Windows 10/11 (x64), не требующая установки Python.

## Что нового в этой версии

- **Whisper `small` по умолчанию + выбор модели в интерфейсе (`Small` / `Medium` / `Large v3`):**
  - прямо на главном экране в карточке **«Модель речи (Whisper)»** заранее видны размер весов, требования к VRAM/RAM, скорость, точность и статус модели на диске (`Готова` или `↓ ~XXX МБ`);
  - кнопку **«Скачать»** можно нажать заранее до запуска видео — отображается живой прогресс-бар, скорость (МБ/с) и оставшееся время;
  - выбранная модель запоминается между запусками (`data/whisper.json`).
- **YouTube 1080p в экономном режиме** и поддержка перерендера готовых эконом-клипов.
- **Live-инспектор (`Ctrl+Shift+D`)** с телеметрией GPU/VRAM, CPU/RAM, Whisper, YouTube и процессов `ffmpeg`.
- **Карточка «Диск и очистка»** в Инспекторе (`Очистить временные` и `Удалить исходники`) без удаления готовых клипов и моделей Whisper.
- **Автопроверка обновлений отключена по умолчанию** (включается тумблером в интерфейсе).
- **Безопасный откат на CPU** при отсутствии CUDA/cuDNN DLL в системе.

## Ограничения лёгкой сборки (без CUDA DLL)

1. **Распознавание речи Whisper работает на CPU**, если в вашей системе не установлены системные библиотеки NVIDIA CUDA 12 + cuDNN 9 (для CPU комфортнее использовать модель `Small` по умолчанию). При этом аппаратное ускорение рендера видео **`h264_nvenc`** на картах NVIDIA продолжает работать через стандартный видеодрайвер.
   - Если вам нужно быстрое распознавание Whisper `Medium` / `Large v3` на видеокарте NVIDIA, скачайте [архив ветки `custom` (ZIP)](https://github.com/hiez1337/viralcut/archive/refs/heads/custom.zip) и запустите через `run_windows.bat` (он автоматически поставит `nvidia-cublas-cu12` и `nvidia-cudnn-cu12`).
2. **Модели Whisper не вшиты в архив** — нужная модель скачается при первом запуске или кнопкой **«Скачать»** в интерфейсе (`Small` ~465 МБ, `Medium` ~1.46 ГБ, `Large v3` ~2.95 ГБ).
3. **Предупреждение Windows SmartScreen** — exe-файл не имеет платной цифровой подписи; при первом запуске нажмите *«Подробнее» → «Выполнить в любом случае»*.
4. **Нужен Microsoft Edge WebView2 Runtime** — уже встроен в Windows 11 и актуальную Windows 10.
5. **Node/PO-token провайдер не вшит** — при ограничениях YouTube включите опцию **«Cookies из браузера»** в параметрах нарезки.

## Как запустить

1. Скачайте `ViralCut-1.4.1-fork.1-windows-x64-lite.zip` ниже.
2. Распакуйте архив в любую папку с латинским путём (например, `C:\ViralCut`).
3. Запустите `ViralCut\ViralCut.exe`.
