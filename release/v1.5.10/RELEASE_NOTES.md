# ViralCut 1.5.10

**Локальная нарезка длинных видео в вертикальные клипы: субтитры, умный кроп по
лицу, паузы, готовые MP4. Всё считается на вашем компьютере — видео никуда не
отправляется.**

В этом релизе два больших исправления: приложение снова открывается на Windows,
а субтитры больше не вылезают за края кадра.

---

## 🪟 Windows: приложение не открывалось

**Что было.** Настольная оболочка запускается через `pythonw.exe` без консоли.
Любая ошибка до открытия окна завершала процесс молча — человек видел «нажал и
ничего не произошло». Вдобавок каждый запрос к базе оставлял открытое соединение
SQLite: на Windows это блокировало файл базы, из-за чего падал CI и не собирался
`.exe` для релиза 1.5.9.

**Что сделано.**

- Соединения SQLite закрываются сразу после запроса.
- Самопроверка при старте больше не может уронить запуск.
- В `app.log` пишутся метки `[boot]` — по ним видно, на каком этапе остановился запуск.
- Если приложение уже запущено, появляется диалог вместо тихого выхода.
- `ViralCut.bat` при неудаче сам открывает консоль с текстом ошибки.
- Опрос GPU перенесён на момент после открытия окна: сбой счётчиков не мешает запуску.

## ✍️ Субтитры: выходили за кадр и выглядели «размытыми»

**Что было.** Ширина строки считалась только под наш шрифт. Если libass
подставлял системный (он шире на 15–20%), строки уезжали за края, а длинное слово
перенести нельзя — вся реплика оставалась одной длинной строкой. Отсюда и жалобы
на «другой шрифт» и текст за рамками.

**Что сделано.**

- Перенос строк минимизирует самую длинную строку, а не разницу сторон.
- Расчёт ширины идёт с запасом на подстановку шрифта.
- Реплика и хук автоматически уменьшают кегль, если строка всё равно не влезает.
- Шрифты для libass читаются напрямую из папки приложения — без копий и симлинков
  в профиле пользователя.
- В лог пишется `[render] шрифты libass: … (N файлов) — OK`.

**Замер** (кадр 1080×1920): было — строка занимает все 1080 px и обрезается;
стало — 797–955 px, края не задеваются ни нашим шрифтом, ни подставленным
системным.

## ⚙️ Установка

**macOS.** Откройте DMG, перетащите приложение в «Программы». Первый запуск —
ПКМ по приложению → «Открыть» (подпись ad-hoc, без нотаризации). Либо в терминале:

```bash
xattr -dr com.apple.quarantine /Applications/ViralCut.app
```

**Windows.** Распакуйте архив целиком (не запускайте из окна ZIP-архива) и
запустите `ViralCut.exe`. SmartScreen покажет «Неизвестный издатель» —
это нормально для неподписанной сборки: «Подробнее» → «Выполнить всё равно».
Для варианта без установки — распакуйте и запустите `ViralCut.bat`.

**Если что-то не открылось:** Windows — `ViralCut-console.bat` покажет ошибку;
дальше `%APPDATA%\ViralCut\app.log`. macOS — `~/Library/Application Support/ViralCut/app.log`.
